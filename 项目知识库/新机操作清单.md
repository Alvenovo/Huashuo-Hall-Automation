# 步骤六 · 兜底：从 GitHub 下代码（可选）

**六 A · 浏览器**：打开 `https://github.com/Alvenovo/Huashuo-Dating-Automation` → 绿色 `Code` →
`Download ZIP` → 解压 → 文件夹改名去掉 `-main` → 放到桌面。

**六 B · 命令行**（要一个 `github_pat_` 开头的细粒度令牌，权限**只要 Contents: Read-only**，
令牌建法见《测试机操作手册.md》；令牌是密码级凭据，不写进任何文件、不贴聊天）：

```powershell
$ProgressPreference = "SilentlyContinue"
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
cd C:\Users\你的用户名\Desktop
$tok = Read-Host "粘贴令牌"
Invoke-WebRequest -Headers @{ Authorization = "Bearer $tok" } `
  -Uri "https://api.github.com/repos/Alvenovo/Huashuo-Dating-Automation/zipball/main" `
  -OutFile repo.zip -MaximumRedirection 5
Expand-Archive repo.zip -DestinationPath _tmp_repo
$inner = Get-ChildItem _tmp_repo | Select-Object -First 1
Move-Item $inner.FullName Huashuo-Dating-Automation
Remove-Item _tmp_repo -Recurse -Force; Remove-Item repo.zip -Force
Remove-Variable tok; Clear-History
Remove-Item (Get-PSReadlineOption).HistorySavePath -ErrorAction SilentlyContinue
```

**两条路都检查**：`cd` 进桌面的 `Huashuo-Dating-Automation` 后 `dir`，
能看到 `AGENTS.md`、`tools`、`tests`、`hall_auto`、`config.yaml`

# 步骤十八 · 人在环（可选，全自动跑完后再做）

**测试机 ｜ 步骤十六那个 agent 窗口 ｜ 备好：测试号 + 能收短信的手机**

全量档跑完后 agent 会自己问「是否现在参与人在环？」。要码顺序固定：
① 短信登录（**真发短信**）→ ② 忘记密码往返（**2 个短信码**，真改两次密码再改回）。
没绑过手机号的账号登录后还会弹「绑定手机号」，那要额外 1 个码。

**做法**：输「能」回车 → 第二问决定改密码这条测不测（不测输「不测」，记为带原因的 skip）→
照提示依次粘码。

⚠️ 2026-10-28 起**不要邮箱码** —— 微软邮箱验证码那条用例已删，只剩上面这两条。
⚠️ 不想参与就**直接回车跳过**，别让问句挂着（挂着 = 控制机看到「执行中」不动，像死机）。
⚠️ 这一步不进农场汇总报告，跑完在**控制机**补一次：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\farm_control.py aggregate
```

错过后补跑，在**测试机**上敲：


# 附：想单独测哪一块 → 投哪个套件

**投任务时 `--suites` 后面写的就是这个「套件名」。** 想只测某一块就投它，
多个用逗号拼（`--suites launch,login`）；**写错了会报错并列出可用的名字**，不会静默投错。

| 想测哪一块 | 套件名 | 要提权吗 | 大概多久 | 在 `all` 里吗 |
| --- | --- | --- | --- | --- |
| 单元 / 守卫（**不碰界面**，纯逻辑与对账） | `unit` | 否 | 约 20 秒 | ✅ |
| 启动 / 搜索 / 详情页（冒烟） | `launch` | 否 | 2-3 分钟 | ✅ |
| 三个列表刷新（**要凭据**，只读不改机器） | `apps-detect` | 否 | 约 1 分钟 | ✅ |
| 登录 / 注册 / 忘记密码 | `login` | 否 | 3-5 分钟 | ✅ |
| 设置 / 主题档位 | `settings` | 否 | 约 1 分钟 | ✅ |
| 安全验证（安装包签名 / 个人空间盘 / 控制面板 / 签章） | `security` | 否 | 2-3 分钟 | ✅ |
| WorkBuddy 入口 | `wb` | 否 | 2-3 分钟 | ✅ |
